LOCAL REBUILD (Windows PowerShell)
----------------------------------
cd codestoreglobal
npm install
npx prisma generate
npx prisma migrate deploy
npx prisma db seed          (optional - adds a featured job sample)
npm run build
npm run start

DEPLOY (Coolify / Vercel)
-------------------------
1. Push this folder to your repo (or upload to Coolify via Git)
2. Coolify: redeploy the app -> build runs automatically (npm install + prisma generate in build)
3. Run migrations ONCE on the server:
     npx prisma migrate deploy
   (or apply prisma/migrations/20261004000000_jobs_monetization/migration.sql manually in MySQL)
4. Vercel (if frontend is there): env vars must be set in Vercel dashboard, then REDEPLOY

VERIFY AFTER DEPLOY
-------------------
1. https://codestore.global/en/marketplace/category/templates        -> category page with copy
2. https://codestore.global/en/jobs                                 -> public jobs board
3. https://codestore.global/sitemap.xml                             -> includes /marketplace/category/... URLs
4. Create a job with "Feature this job" checked -> amber Featured badge on tenant + public boards
5. Upload a 5MB product image -> succeeds (compressed client-side)
6. Submit sitemap.xml in Google Search Console
